# Known gaps of the ovos-bus-client session graft against the SESSION-1
# named-session contract, measured on the OVOS distro "alpha" release channel.
#
# The cell behind this file is the `session-graft` job in
# .github/workflows/channel_compat.yml. It installs the alpha channel stack,
# puts ovos-spec-tools@dev on top, loads ovos_bus_client.session so its graft
# lands on ovos_spec_tools.session.SessionManager, and runs spec-tools' own
# test/test_session_manager.py against the grafted store. Node ids are
# relative to this repository's root, where the spec-tools checkout sits at
# ovos-spec-tools/.
#
# Each line is a pytest node id that FAILS under the graft and passes without
# it. These are defects in the grafted store, not harness problems, so the job
# xfails exactly these and stays green — anything NOT listed here that breaks
# turns the job red.
#
# The xfails are strict. A listed node that starts PASSING also turns the job
# red: the graft caught up and the line must be deleted. A listed node that
# no longer exists fails the run too, so a renamed test cannot rot in here.
#
# Reproduce locally:
#
#   git clone -b dev https://github.com/OpenVoiceOS/ovos-spec-tools ovos-spec-tools
#   test/channel_compat/install_channel.sh alpha
#   pip install --no-deps ./ovos-spec-tools
#   OVOS_CHANNEL=alpha-session-graft pytest ovos-spec-tools/test/test_session_manager.py \
#     -p ovos_bus_client.session -rxX
#

#   [xpass]    node ids the suite marks xfail(strict) for a reason that does
