# OVOS spec stack under test — the combo selector.

# Each line below is a *pin* for one repo in the integrated spec stack. This
# file (NOT a `pip install .[test]`) is what gets installed in CI, so pip's
# resolver is handed an explicit, fully-pinned set of git refs and never gets
# the freedom to downgrade or re-resolve a transitive dep out from under the
# combination we are trying to validate.
#
# To validate a DIFFERENT combination of unmerged branches: edit the refs here
# and open a PR — CI then installs exactly that stack and runs the full spec
# conformance suite against it. As each branch merges, flip its ref to @dev.
#
# Limitation: two branches of the SAME repo cannot both be installed; pick one
# ref per repo.
